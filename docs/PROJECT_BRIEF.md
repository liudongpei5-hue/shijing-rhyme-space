# 项目简报

## 核心概念

网页本身是一座可穿行的三维中古音韵空间。用户输入诗句后，整句文字共同浮起并进入空间；每个字分别漂向自己的音韵格位，来自 X、Y、Z 三轴的光场在字上交叠，凝结为可追溯的音印。全句完成后停留在总览，观众可点击单字近看其音韵结构。点击“生成印谱”后，各枚音印按照诗序错峰滑入竖向词卡。

## 第一阶段范围

- 示例：七月流火，九月授衣。
- 输入：固定示例句，同时保留未来任意文本输入接口。
- 输出：竖向词卡 PNG。
- 暂不纳入：实时 AIGC、完整切韵字库、TTS、后台登录。

## 学术结构

- 内部标准：锁定版本的 TshetUinh 音韵地位。
- 文献依据：《广韵》字头、反切、小韵与来源。
- 空间参考：《韵镜》式韵图的声母、韵类、四声组织方式。
- 三轴暂定：X 为声母，Y 为韵类，Z 为平、上、去、入四声。
- Z 轴为离散类别层，不宣称表示实际音高。
- 中古音用于“切韵音系下对《诗经》的声音重释”，不宣称复原先秦真实语音。

## 观众流程

1. 输入诗句并按 Enter。
2. 全句共同浮起，以轻微错峰进入空间。
3. 各字同步寻位，三轴光场分别响应。
4. 音印在字后由空间投影层叠生成。
5. 镜头退至能够囊括全句的总览位置。
6. 点击单字，镜头沿固定轨道推进并展开详情。
7. 返回总览。
8. 点击“生成印谱”。
9. 音印按诗序、相互重叠地滑入竖向词卡。
10. 导出 PNG。

## 视觉方向

不是通用科幻霓虹界面，而是“古籍韵图成为一座暗色空间仪器”：冷灰或矿物色结构光负责定位，银白表示当前寻位，朱砂只用于成印与最终词卡。界面文字克制，空间承担主要叙事。

## 工程边界

- `phonology/`：数据查询、校验和坐标推导。
- `scene/`：三维空间、相机、格位和光场。
- `motion/`：进入、定位、总览、近看和成谱时间线。
- `seal/`：确定性音印生成。
- `card/`：竖向词卡排版与导出。
- 页面组件不直接持有复杂时间线。
- 连续动画值不进入 React 高频渲染状态。
- 坐标由纯函数生成，不在场景中手工写死。

## 未决事项

- 锁定 TshetUinh 具体版本与数据快照。
- 审定八字的《广韵》音韵地位及语境读音。
- 明确 Y 轴韵类排序与《韵镜》各转的对应方式。
- 确定音印从三轴投影到二维印面的算法。
- 确定竖向词卡实际尺寸和印刷分辨率。
