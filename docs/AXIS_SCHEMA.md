# 三维坐标简化方案

## 结论

- X轴：切韵音系38声母，不直接压缩为宋代三十六字母。
- Y轴：平、上、去、入四声，作为高度层。
- Z轴：通、江、止、遇、蟹、臻、山、效、果、假、宕、梗、曾、流、深、咸十六摄，作为远近纵深。
- 字内信息：具体韵、等、开合与重纽保留在详情和音印构形中，不继续增加坐标轴。

## 为什么不是36声母

三十六字母属于较晚的韵图传统。它适合解释宋代韵图的声母框架，但会合并《切韵》音系中庄组、章组等区别。项目的字音数据来自 TshetUinh 所表达的切韵音系，因此X轴保留38类，以免位置因视觉简化而失真。

## 为什么Z轴使用16摄

《韵镜》把《广韵》206韵归入16摄，再依据等、呼等条件分为43转。把43转或206韵全部铺成空间主轴会显著提高视觉负担。16摄可以保持各韵的大类归属和原有次序；更细的韵、等、开合、重纽仍保留在数据层，点击字时呈现。
