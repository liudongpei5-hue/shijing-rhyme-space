# 聚束方法与比较约定

依据：Holten, D.; van Wijk, J. J. (2009). Force-Directed Edge Bundling for Graph Visualization. Computer Graphics Forum 28(3), 983–990. DOI: 10.1111/j.1467-8659.2009.01450.x。

实现依据原文§3.2的角度、尺度、位置、可见性四项相容度乘积，以及§3.3的渐进细分。固定端点；相邻细分点弹簧力与对应点间反距离吸引力共同决定移动方向。

统一项目参数：K=0.085；相容度阈值0.05；P=1,2,4,8,16,32；S=.04,.02,.01,.005,.0025,.00125；I=50,33,22,15,9,7。P/S/I依据原文§3.3；K由0.1统一调整至0.085以略增强聚束；K与阈值为本项目选定参数，不声称是原论文唯一标准。

项目改编：计算扩展至三维欧氏坐标；反向边先对齐细分顺序；最终使用Catmull–Rom曲线显示。暂未实现论文的局部冷却及Gaussian后处理。线宽以邻近路径密度估计，属于项目表现方法，不是论文§4.1的像素累积着色复现。

跨诗比较须保持同一分类轴、坐标比例、视角、参数与渲染规则；保留字序边及重复次数。聚束形态仅提供重复与过渡模式线索，需通过单句高亮和数据统计核查，不能直接视作押韵或历史语音结论。
